## About
Transformer architecture has enabled AI tools such as ChatGPT, Google Search, and Google Translate. In this module we will dive how the transformer architecture works and apply select models from the transformer family to solve a real-world problem.


## Learning Objectives

*You will be able to:*

- Explain how probabilistic language models generate text.
- Describe transformer architecture: encoders, decoders, and encoder-decoders.
- Evaluate which architecture to use for common NLP business applications.
- Apply enocoder architecture to a Named Entity Recognition (NER) task.
- Apply decoder architecture to a text generation task.
- Apply enocoder-decoder (seq2seq) architecture to a translation and summarization task.
